. GIT e GIT HUB

O QUE SÃO ?

.git é um sistema de controle de versao para gerenciar alteraçoes no codigo

. git hub é uma plataforma online que hospeda repositórios git e facilitar a colaboraçao entre desenvolvedores

. FUNÇÕES

.Rastrear mudanças em arquivos (código, documentos, etc.).

. Criar versões (commits) que registram o estado do projeto.

.Trabalhar com branches, permitindo desenvolver novas funcionalidades sem afetar o código principal

.trabalhar offline, já que tudo funciona localmente.
